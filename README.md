# 📊 Tableau Data Visualisation Project
### Data Technician Bootcamp | Interactive Dashboards & Data Storytelling

## 🚀 Project Overview

As part of my **Data Technician Bootcamp**, I developed a series of interactive Tableau dashboards to analyse and communicate insights from retail, sales, and analytical datasets. The project focused on transforming raw data into compelling visual stories through dashboards, filters, calculated fields, and a variety of chart types. Based on work completed in Data_Technician_Workbook_Week_2_ Tableau_Only.docx. 【1-4aa323】

The aim was to create intuitive, user-friendly visualisations that enable stakeholders to explore trends, identify patterns, and make data-driven decisions.

## 📖 Data Storytelling Approach

A key focus of this project was using Tableau to tell a clear story with data rather than simply displaying charts.

The dashboards were designed to:

1. Present high-level business metrics
2. Highlight important trends and patterns
3. Allow users to investigate underlying causes
4. Support decision-making through visual evidence

By combining multiple visualisations into a single interactive dashboard, users can quickly move from overview insights to detailed analysis.
